# VoxEngine

[English](README.md) | **简体中文**

**VoxEngine** 是一款**端侧原生 AI 歌声合成（SVS）引擎**，面向个人极客与低配移动设备。

核心使命是摆脱昂贵的云端算力、卡顿的浏览器外壳（WebView）与繁琐的本地编译环境，
让老旧设备也能做到毫秒级、高质量 AI 歌声输出，让人人都能用上私密、离线、轻量的歌声创作。

## 核心特性

- **原生轻量架构**：完全抛弃笨重的 WebView 容器。自研原生 UI 与进程调度，内存占用极低，
  帧率稳定。解决移动端 AI 合成常见的卡顿、延迟、后台被杀问题。
- **完全离线本地推理**：所有推理、渲染、解析都在设备端完成。无需联网，零数据上传，
  零隐私风险。断网状态下功能完整，实现真正私密的 AI 音频创作。
- **可控「人味」系统**：自研「人味滑块」机制，支持完美度的无缝渐变控制。
  一键在「毫无瑕疵的机械完美」与「自然的人味瑕疵」（气息波动、音高偏移、情绪细节）之间切换。
- **极速异步渲染管线**：采用分算力架构与并行调度逻辑，打破传统逐帧串行合成瓶颈，
  支持长音频快速渲染，生成速度接近流媒体。
- **热插拔「卡带」引擎机制**：开创性地将 UI 与核心引擎完全解耦。
  模型、推理运行时、声库全部模块化，升级/更换/回滚引擎如同换游戏卡带——秒级部署，无需重装应用。

## 宏观技术路线

- **三层架构**：严格分离「UI 渲染与调度层」「业务逻辑分发层」「计算引擎层」。
  分层解耦、职责独立，确保极致的稳定性、可扩展性与可迭代性。
- **混合渲染（物理声学 + 轻量神经模型）**：用低功耗物理声学算法（Rosenberg/LF 声门脉冲 +
  5 腔共振峰级联）生成高精度、稳定的歌声骨架与音高曲线；再用轻量神经扩散模型
  填充细节、润色质感、赋予个性与情感，兼顾速度、精度与设备兼容性。
- **全异步非阻塞管线**：打破传统串行合成逻辑，采用异步并行队列处理，
  实现毫秒级响应、无卡顿多任务与不阻塞的连续生成。
- **开放可控的数据生态**：开放可编辑的工程节点结构（纯文本 JSON），
  创作者可自由修改歌词、音高、动态、气息与风格参数；
  配合私有加密打包标准，兼顾开放性、可扩展性与版权安全。

## 项目路线图

- **Phase 1（V1.0 物理骨架）**：完成基础物理声学核心、基础调度逻辑与简单合成闭环，
  验证底层可行性。**（当前阶段）**
- **Phase 2（V2.0 高精度合成器）**：引入 LF 声门模型与波导声道模型，
  补齐辅音与鼻音；用 WebAssembly（WASM）释放性能。

## 快速开始

> 完整的构建说明、目录结构、ONNX 配置与训练流程见 **[BUILD.md](BUILD.md)**。

```bash
# 依赖
pkg install clang make gtk3 pkg-config

# 编译主界面
clang++ -O2 -std=c++17 -Isrc -o bin/vox_gui src/gui_main.cpp \
  $(pkg-config --cflags --libs gtk+-3.0) -lm

# 自检（33 项断言，不需要开窗口）
./bin/vox_gui --selftest
```

**当前已实现**（Phase 1 物理骨架）：

- LF 声门源 + 5 共振峰全极点级联 + Klatt 式并联高频支路
- 中英日共 110 个音素，CV 音节自动拆分（`ni hao` / `ka ki` / `hh eh l ow`）
- 跨音符连续渲染（声门相位与声道状态保持）
- X11 卷帘编辑器：多轨、每轨独立参数、中键框选、Ctrl+C/V、多轨全览
- ONNX 推理接口（可选；无模型时自动回落纯参数合成，零开销）
- 全自动训练流水线：文件夹校验 → YIN 提音高 → 造对齐成对数据 → 生成训练脚本
- **界面支持中文 / English 双语**（设置面板可切换）
